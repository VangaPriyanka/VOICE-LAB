# 🎙️ VoiceLab

VoiceLab is an AI-powered multilingual voice processing web application built using Flask, Whisper AI, gTTS, and Deep Translator.

The application supports:

* 📝 Text to Voice
* 🎤 Voice to Text
* 🌐 Voice Translator
* 🎙️ Live Voice Recording
* 📱 Responsive UI
* 🌙 Dark/Light Theme
* ⬇️ Audio Download
* 📋 Copy Text Feature

# 🎯 Features

## 📝 Text to Voice

Converts entered text into speech in multiple languages.

## 🎤 Voice to Text

Converts uploaded or recorded speech into text using Whisper AI.

## 🌐 Voice Translator

Converts speech from one language into translated speech in another language.
